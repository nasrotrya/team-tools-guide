

\# Contributing Guide



\## How to Contribute



1\. Clone the repository.

2\. Create a new branch.

3\. Make your changes.

4\. Commit your changes.

5\. Push your branch.

6\. Open a Pull Request.



\## Code Guidelines



\- Write clear and readable code.

\- Use meaningful commit messages.

\- Document your changes.

\- Review other contributions.
